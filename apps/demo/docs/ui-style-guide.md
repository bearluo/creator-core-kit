## 风格定义

**明亮休闲卡通**——蓝天草地基调，圆润讨喜的吉祥物，高饱和、厚白描边、大圆角、柔和渐变与高光。参照消除 / 合成类休闲手游的加载页。

**不要**：深色科技感、霓虹赛博、写实渲染、3D 界面透视、扁平极简、暗色磨砂玻璃。

## 调色板

数值是从参考稿目测取的近似值，**以真图为准**；作新元素配色时对齐这一组，别另起炉灶。

| 用途 | 近似色 |
|---|---|
| 天空（上→下渐变） | `#1E90E8` → `#8FD6FF` |
| 草地（远→近） | `#6FBF3E` → `#A8DE6B` |
| 角色主色 | `#5AAEF0`，暗部 `#3B8ED8`，腹白 `#EAF4FC` |
| 强调色（logo 主字、按钮、TIP 文字） | `#FFC020` → `#FFA51F` 渐变，亮部 `#FFD966` |
| logo 副字 / 深蓝描边 | `#1B4E9B` |
| 状态文字 | 纯白 `#FFFFFF` + `#1B4E9B` 外描边（**不用深蓝实心字**） |
| 描边 / 高光 | `#FFFFFF`，厚描边，所有主要元素都有 |
| 进度条：已完成 / 未完成 | `#4FA8F0` / `#2E6FBF`（未完成是**更深的蓝**，不是浅灰） |

## 造型语言

- **大圆角**：按钮 / 卡片圆角半径约为其高度的 1/3，进度条直接做成胶囊形。
- **厚白描边**：主要元素（logo、按钮、进度条、角色）一律有一圈白描边，这是本风格的识别特征。
- **柔和立体**：内侧高光 + 底部落影，不用硬阴影、不用长投影。
- **字重厚**：标题用粗圆体带描边；正文字号别小于 20（1080 宽设计分辨率下）。

## 状态规则（重要）

**同一个界面的不同状态，只换该换的东西——不换皮。**

失败态不是另一套界面：背景、logo、角色、配色、各元素位置全部保持不变，只改：

| 变的 | 不变的 |
|---|---|
| 状态文案（→ 错误提示） | 背景插画 |
| 提示文案（→ 排查引导） | 标题 / logo |
| 角色表情（开心 → 担心，同一个角色） | 角色本身、位置、尺寸 |
| 多出一个操作按钮 | 进度条（停在失败时的进度，不清零） |

这条基本对齐 `LaunchOverlay.ts` 的实现：`onFailure` 只改文案、显形 `Action` 按钮，不碰进度条。

**一处待对齐**：代码里 `onFailure` 会把状态文字染红（`C_ERR = (255,120,110)`），但参考稿的失败态文字仍是「白字 + 深蓝描边」，靠角色表情和 `CONNECTION LOST` 措辞传达失败，不靠变色。本风格下红字会显脏。真正接美术资源时，把 `C_ERR` 去掉、或换成同色系的暗调。

## 当前能落地到什么程度

demo 里的 prefab 目前**只用引擎内置的两张图**（纯白块 + 九宫格圆角按钮底），靠染色和堆叠出层次：

- ✅ 做得到：配色、间距、层次、圆角按钮、胶囊进度条。
- ❌ 做不到：插画背景、角色、带描边的艺术字 logo、渐变、高光。

要拿到参考稿那种质感，必须走完整链路：**出 PNG → 放进 `assets/` → Creator 导入 → 取 spriteFrame uuid → 写进描述 JSON 或在编辑器里接上**。这条链没走之前，prefab 只能是「排版对了、质感没到」的状态，属预期，不是 bug。

## 让模型出符合本风格的新图

复用 `scripts/prefab-gen/README.md` 里那套 spec 骨架，把 `Style/medium` 和 `Avoid` 两段换成本文的「风格定义」，并把调色板贴进 prompt。关键约束照抄：

- 平视 2D 界面构图，无手机边框、无透视；
- 文字只用简短英文占位，字少、别堆成乱码；
- 要出「同一界面的多个状态」时，**显式写明背景 / logo / 角色 / 配色 / 元素位置必须完全一致**——不写的话模型默认会画成两个不同方案（踩过）。
