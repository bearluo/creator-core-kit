# i18n 设计文档

## TL;DR

`createI18n({ locale?, fallbackLocale?, tables?, logger? })` 返回一个 `I18n`：`t('menu.start')` 查当前 locale 的扁平点键表，`t('hi', { name })` 做 `{name}` 插值；查不到走 `fallbackLocale`，再查不到返回 key 本身并去重告警。`setLocale(loc)` 运行时切换并 `onChange` 广播；`addTable(loc, table, merge?)` 运行时追加/合并翻译（嵌套对象自动拍平为点键）。**纯逻辑、零 cc**——godot 版托管引擎 `TranslationServer`，本框架守铁律不碰 cc，故 core 只做「字典查表 + 插值 + 回退 + 切换事件」，字体随 locale 切换、翻译资源加载、语言持久化都落 engine/app 侧。

## Purpose（目标与定位）

- **做什么**：给游戏一个单点本地化层——按 key 取当前语言译文、运行时切语言、运行时追加翻译表。
- **定位/取舍**：Cocos Creator **无内置 i18n**（不像 Godot 有全局 `TranslationServer`），社区多用「`{ en:{...}, zh:{...} }` 字典 + `t(key)`」方案。core 正是这个纯字典内核；它不替代引擎任何东西，是自带的增值层。
- **与相邻模块**：独立子系统，可选。告警走 [[logger]]，订阅返回复用 [[eventbus]] 的 `Disposer`。**不**直接依赖 [[save-manager]]/`IStorage`——语言持久化交给 app 接线（见决策 3）。
- **YAGNI（首版砍）**：复数形式（ICU plural）、母语显示名、按 locale 的日期/数字格式化、字体回退（引擎侧）、语言持久化内置——都不做，有真实需求再加。godot 版也砍了 plural 与母语名。

## Public API（TypeScript 精确签名）

```ts
export type LocaleTable = Record<string, string>;        // 扁平点键 → 模板串
export type LocaleTableInput = Record<string, unknown>;  // addTable 输入，可嵌套（自动拍平）
export type I18nParams = Record<string, string | number>;

export interface I18nOptions {
  locale?: string;                              // 初始语言，默认 'en'
  fallbackLocale?: string;                      // 回退语言，默认 = 初始 locale
  tables?: Record<string, LocaleTableInput>;    // 预置表，值可嵌套
  logger?: ILogger;                             // 默认 getLogger('I18n')
}

export interface I18n {
  readonly locale: string;
  readonly fallbackLocale: string;
  setLocale(locale: string): void;              // 空串→告警no-op；同当前→no-op；无表→告警但仍切；成功广播 onChange
  addTable(locale: string, table: LocaleTableInput, merge?: boolean): void;  // merge 默认 true 叠加
  t(key: string, params?: I18nParams): string;  // 当前→fallback→key；{name} 插值
  has(key: string, locale?: string): boolean;   // 只查指定/当前 locale，不查 fallback
  availableLocales(): string[];
  onChange(cb: (locale: string) => void): Disposer;
}

export function createI18n(opts?: I18nOptions): I18n;
export const I18N: Token<I18n>;
export function getI18n(): I18n;                 // tryResolve(I18N) ?? 进程默认单例
```

## Behavior & data flow（行为与数据流）

- **内部结构**：`tables: Map<locale, LocaleTable>`（每 locale 一张扁平点键表）+ `listeners: Set<cb>`（onChange 订阅）+ `warned: Set<'locale|key'>`（缺翻译告警去重）。`locale` 可变、`fallbackLocale` 不可变。
- **t(key, params)**：`tables[locale][key]` → 若无且 `fallback!==locale` 则 `tables[fallback][key]` → 若仍无 `warnMissing(key)` 并返回 `key`。命中则 `interpolate(tpl, params)`。
- **插值**：正则 `/\{(\w+)\}/g` 替换；命中参数用 `String(value)`（数字转串），**缺参数保留原占位符** `{name}`（便于发现漏传，不静默变空）。无 `params` 直接返回模板。
- **addTable**：把（可能嵌套的）输入递归拍平进临时扁平表——`string` 直存、`number` 转串存、**纯对象**递归下钻（点键拼接）、其余（数组/布尔/null）**告警跳过**。`merge=true`（默认）`Object.assign` 叠加到已有表，`false` 整表替换。空 locale 告警忽略。
- **setLocale**：空串告警 no-op；等于当前 no-op（不重复广播/落盘由外部管）；目标无表则告警（拼写错/表未加载）但**仍切换**（表可后补、fallback 兜底）；切换后遍历 `listeners` 广播，单个回调抛错被 try/catch 隔离 + 告警，不影响其它订阅。
- **零 cc 边界**：core 全在纯 TS。**engine/app 侧**负责：① `i18n.onChange(loc => 换字体/刷新 UI)`；② 用 `IAssetLoader` 加载翻译 JSON 后 `addTable`；③ 语言持久化 `onChange(loc => settings/save)`、启动 `setLocale(读回的值)`。

## Key design decisions（决策表）

| # | 维度 | 选项 | 选定 | 理由 |
|---|---|---|---|---|
| 1 | 插值语法 | **`{name}`** / `{{name}}` / `%s`·`{0}` | **`{name}`** | ICU/vue-i18n 风格，正则简单、可读性好、配表最常见（**定稿**） |
| 2 | key 结构 | **扁平点键** / 嵌套对象 | **扁平点键** | 查找 O(1)、实现最简、热更 merge 直接；嵌套 JSON 在 addTable 时自动拍平，两头都占（**定稿**） |
| 3 | 语言持久化 | **app 外部接线** / core 注入 IStorage | **app 外部接线** | core 保持纯 + 同步 setLocale；避免把异步 IStorage 塞进同步切换；与 Settings 语义解耦（**定稿**） |
| 4 | 缺翻译 | 抛错 / 返回空 / **返回 key + 去重告警** | **返回 key** | 永不崩、UI 退化可见（显示 key）、debug 帮发现漏翻（对齐 godot `t()`） |
| 5 | 回退链 | 无 / **当前→fallback→key** | **三级回退** | fallback 补主语言、key 兜底；`has()` 不查 fallback（问的是具体 locale 有没有） |
| 6 | 切到无表 locale | 拒绝 no-op / **告警但仍切** | **仍切** | 表可能后加载；拒绝会卡住「先 setLocale 再 addTable」的加载顺序 |
| 7 | onChange 回调抛错 | 冒泡中断 / **隔离 + 告警** | **隔离** | 一个订阅崩了不该拖垮其它订阅与切换本身 |

## Platform considerations（全平台 / 小游戏兼容）

- 纯 TS（`Map`/`Set`/正则），node/web/所有小游戏/原生无差异，零 IO、零 cc。
- **翻译资源加载**：core 只吃已解析的对象（`addTable`）。engine 用 [[asset-manager]]/`IAssetLoader` 加载 `i18n/en.json` 等，小游戏分包同理；DLC/热更翻译运行时 `addTable` 追加即可（对齐三种"热"里的运行时分包）。
- **字体随语言切换**（CJK 字体等）是引擎侧副作用：`i18n.onChange` 里换 `Label` 字体，core 不涉。
- **持久化**：语言是跨存档的玩家偏好，应走 Settings（engine 用 `cc.sys.localStorage` 适配的 `IStorage`），**不要**塞进 [[save-manager]] 存档槽。

## Testable seams + test plan（可测接缝 + vitest 用例）

- **可测性**：全纯 TS 零 cc；告警注入 fake logger 断言，onChange 用数组记录断言，无需 mock cc。
- **用例**（18 条，见 `i18n.test.ts`）：查表+插值 / 数字转串+缺参保留占位 / setLocale 切换+广播 / 空串告警+同当前不广播 / 切无表 locale 告警仍切 / fallback 回退 / 缺翻译返回 key+去重告警（跨 locale 再告警）/ addTable merge 叠加与替换 / 嵌套拍平+数字转串 / 非法叶子告警跳过 / 空 locale 告警 / has 只查指定 locale / availableLocales / Disposer 取消订阅 / 回调抛错隔离+告警 / fallback 默认=locale / getI18n token 优先+默认单例 / 默认 locale=en。
